# 📂 Dataset

## Source

The dataset used in this project was sourced from Kaggle.

The original dataset contains e-commerce product, seller, pricing, sales,
inventory, rating, delivery and return-related information.

## Dataset Purpose

The dataset was used to analyze e-commerce business performance and identify
patterns related to:

- Sales and revenue
- Products and categories
- Brands
- Sellers
- Pricing and discounts
- Inventory
- Product ratings and reviews
- Delivery performance
- Return policies

## Main Columns

- product_id
- product_name
- category
- brand
- seller
- seller_city
- price
- discount_percent

- rating
- review_count
- stock_available
- units_sold
- listing_date
- delivery_days
- weight_g
- warranty_months
- color
- size
- return_policy_days
- is_returnable
- payment_modes
- shipping_weight_g
- product_score
- seller_rating

## Data Preparation

The dataset was imported into Power BI and cleaned and transformed using
Power Query.

The preparation process included:

- Data type validation
- Data cleaning
- Data transformation
- Column formatting
- Preparation of fields required for analysis
