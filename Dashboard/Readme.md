# 🖼️ Dashboard Screenshots

This folder contains screenshots of the Power BI E-Commerce Analytics
Dashboard.

## Dashboard Pages

### 01 - Executive Overview

Provides a high-level summary of sales, revenue, products, categories,
brands, seller cities, inventory, delivery and return-related metrics.

### 02 - Product Analytics

Provides detailed analysis of product, category and brand performance.

### 03 - Seller Analytics

Provides analysis of seller performance, seller ratings, revenue and
seller-city performance.

### 04 - Pricing & Inventory

Provides analysis of pricing, discounts, stock availability and
slow-moving inventory.

### 05 - Delivery & Customer

Provides analysis of delivery performance, product ratings, reviews
and return-related metrics.

### 06 - Insights & Recommendations

Summarizes key business insights and provides actionable recommendations
based on the analysis.
