# 📊 Power BI Dashboard

This folder contains the Power BI dashboard file developed for the
E-Commerce Analytics project.

## File

`E-Commerce_Analytics_Dashboard.pbix`

## Dashboard Pages

The Power BI dashboard contains the following analytical pages:

### 1. Executive Overview

Provides an overall view of e-commerce business performance through:

- Total Revenue
- Total Units Sold
- Total Products
- Average Rating
- Average Discount
- Average Delivery Days
- Revenue by Category
- Monthly Revenue Trend
- Revenue by Seller City
- Top Products
- Brand Performance
- Inventory Overview
- Delivery & Returns

### 2. Product Analytics

Analyzes product, category and brand performance including:

- Top Products
- Category Performance
- Brand Performance
- Units Sold
- Revenue
- Ratings
- Reviews
- Product Scores

### 3. Seller Analytics

Analyzes seller performance using:

- Seller Revenue
- Units Sold
- Seller Rating
- Seller Performance
- Seller City
- Revenue Contribution

### 4. Pricing & Inventory

Analyzes:

- Product Prices
- Discount Percentage
- Discount vs Units Sold
- Stock Availability
- Low Stock Products
- Slow-Moving / Dead Stock

### 5. Delivery & Customer

Analyzes:

- Average Delivery Days
- Delivery by Category
- Delivery by Seller Location
- Product Ratings
- Review Counts
- Returnable Products
- Return Policy Distribution

### 6. Insights & Recommendations

Summarizes important findings from the analysis and provides actionable
recommendations related to:

- Revenue
- Pricing and Discounts
- Products
- Sellers
- Inventory
- Delivery
- Returns
- Customer Satisfaction

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
